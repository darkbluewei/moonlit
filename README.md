# 任务管理器（macOS 原生 SwiftUI）

仿 Windows 任务管理器的 Mac 版：进程、性能、启动项、详细信息四个页面，两套界面风格可一键切换。

## 功能

- **进程**：按“应用 / 后台进程 / 系统进程”分组，同一应用的多个进程（如 Chrome）合并成可展开的一行；CPU、内存、磁盘、网络列按占用高低着色（热力图）；点列头排序，顶部搜索；结束任务 / 强制结束 / 在 Finder 中显示 / 复制 PID。
- **性能**：CPU、内存、磁盘、网络、GPU（读得到才显示）、电池（有电池才显示，含健康度、循环次数、温度、实时功率）的 60 秒实时曲线；CPU 可切换为每个逻辑核心；内存带组成条（App / 固定 / 压缩 / 缓存）。
- **启动项**：列出 LaunchAgents / LaunchDaemons，可筛选“自动运行”，只读。
- **详细信息**：按 PID 平铺的完整表格，含路径。
- **两种风格**（左下角切换）：**原生**＝毛玻璃 + 系统字体 + 自动跟随浅色/深色；**仪表盘**＝深色底 + 渐变光晕 + 发光曲线。
- **刷新速度**：高 0.5 秒 / 正常 1 秒 / 低 3 秒 / 暂停。
- **全局快捷键 ⌃⌥/**（Control + Option + /）：任何时候按下都会把任务管理器呼出到最前面；窗口关闭、最小化或被完全遮挡时，会自动暂停采集（也会暂停 nettop），回到前台后继续。
- **仪表盘风格的性能页是监控大屏**：CPU、内存、磁盘、网络、GPU（有电池时再加电池）各一张大卡片，带圆环仪表和实时曲线，一屏摊开；原生风格保持“左侧列表 + 右侧详情”。

## 构建（二选一）

### A. 在自己的 Mac 上
1. 终端运行 `xcode-select --install` 安装命令行工具（已装 Xcode 可跳过）。
2. 在本文件夹运行：`bash build.sh`
3. 生成 `build/MacTaskManager.app`，拖进“应用程序”即可。

### B. 云端构建（不想装开发工具）
1. 在 GitHub 新建一个仓库，把本文件夹的全部内容（包含隐藏的 `.github` 文件夹）上传。
2. 打开仓库的 **Actions** 页面，运行 “Build macOS app”（推送后会自动运行）。
3. 完成后在该次运行页面底部的 **Artifacts** 下载 `MacTaskManager`，解压得到 `.app`。

## 第一次打开

应用没有开发者签名，第一次需要：在 `MacTaskManager.app` 上 **右键 → 打开 → 打开**。
如果提示“已损坏”（从网上下载的压缩包常见），在终端运行：
`xattr -cr /path/to/MacTaskManager.app`

## 限制（macOS 本身的限制）

- **磁盘列**：只有能读取到的进程（一般是你自己的进程）有数值，其它显示“—”。
- **网络列**：来自系统自带的 `nettop`，属于尽力而为；如果在你的系统上读不到，整列显示“—”。
- **CPU / GPU 温度**：通过 SMC 尽力读取（自动枚举传感器，取最高值），读不到时显示“—”。风扇转速和 CPU 功耗这一版没有做。
- **电池功率**：充电时显示“充电功率”，使用电池时显示“放电功率”，接着电源但没在充电时显示“电池功率”；电池健康度读不到时显示“—”。
- 普通权限只能结束你自己的进程；`launchd`、`kernel_task`、`WindowServer`、`loginwindow` 会被禁止结束。
- 系统 / 其它用户的进程，内存和 CPU 为近似值（来自 `ps`），你自己的进程为精确值。
